# Alternate intro films (not used by the site)

`automa-intro-photo.*` is the desk-by-the-window intro with the black-and-white framed photo in the back-left corner.

To switch to it, swap these with the live files in `assets/`:

- `intro-alt/automa-intro-photo.mp4` ↔ `automa-intro.mp4`
- `intro-alt/automa-intro-photo.webm` ↔ `automa-intro.webm`
- `intro-alt/automa-intro-photo-poster.jpg` ↔ `automa-intro-poster.jpg`
