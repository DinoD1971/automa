# Colombia intro

`automa-intro-medellin.*` is the intro film with Medellín outside the window (the Palacio de la Cultura, the Metro and the Parque de las Esculturas), instead of the Minneapolis skyline. The pencil caption reads "primer boceto · 11 ago 2026". It keeps the standard cut's timing and soundtrack.

`index.html` plays it for visitors whose device is set to Colombia's time zone (`America/Bogota`); everyone else gets `assets/automa-intro.*`.

Preview either cut on any device:

- `?intro=co` — the Medellín cut
- `?intro=std` — the standard cut
