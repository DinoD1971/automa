# Colombia intro

`automa-intro-photo.*` is the desk-by-the-window intro with the black-and-white framed photo in the back-left corner.

`index.html` plays it for visitors whose device is set to Colombia's time zone (`America/Bogota`); everyone else gets `assets/automa-intro.*`.

Preview either cut on any device:

- `?intro=co` — the framed-photo cut
- `?intro=std` — the standard cut
